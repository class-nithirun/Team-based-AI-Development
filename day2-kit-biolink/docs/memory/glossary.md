# Glossary (คำศัพท์ ↔ ชื่อในโค้ด)

| คำ | ความหมายในระบบ | ชื่อในโค้ด |
|---|---|---|
| บุคลากร / ผู้ใช้ | เจ้าของโปรไฟล์ที่ล็อกอินได้ | ตาราง `users`, `req.user.id` |
| บทบาท | บุคลากรทั่วไป / หัวหน้า (ผู้อนุมัติ) / ผู้ดูแลระบบ | `role`: `staff`, `head`, `admin` |
| หน้า Public | หน้าโปรไฟล์ที่คนทั่วไปเปิดได้โดยไม่ต้องล็อกอิน | `/u/:username`, `PublicProfile.jsx` |
| ส่วนบนหน้า Public | บล็อกที่ feature เสียบเพิ่มในหน้า Public | `PUBLIC_SECTIONS` ใน `lib/features.js` |
| เมนู Dashboard | เมนูของ feature ในหน้าหลังล็อกอิน | `FEATURE_NAV`, `/dashboard/<ชื่อ>` |
| PD | ระบบข้อมูลบุคลากรของมหาวิทยาลัย (อ่านอย่างเดียว ไม่เขียนกลับ) | `PD_API_URL`, `repositories/remote.js` |
| งานวิจัย | ผลงานวิจัยของบุคลากร (กลุ่ม 1) | ตาราง `research` |
| ประวัติ (CV) | การศึกษา ประสบการณ์ รางวัล ทุน (กลุ่ม 1) | ตาราง `cv_entries` |
| รายวิชา | วิชาที่สอน ตามภาคเรียนและปีการศึกษา (กลุ่ม 2) | ตาราง `courses` |
| เอกสารประกอบการสอน | สไลด์ ประมวลรายวิชา แบบฝึกหัด ของรายวิชา (กลุ่ม 2) | ตาราง `course_materials` |
| แคมเปญ QR | QR ที่มีรหัสติดตามแหล่งที่มา (กลุ่ม 3) | ตาราง `qr_campaigns`, `?src=qr&c=<code>` |
| เหตุการณ์เข้าชม/คลิก | บันทึกรายครั้งพร้อมเวลาและแหล่งที่มา (กลุ่ม 3) | `visit_events`, `click_events` |
| คำขอ | คำขอเอกสารหรือขออนุมัติที่บุคลากรส่งถึงหัวหน้า (กลุ่ม 4) | ตาราง `doc_requests` |
| สถานะคำขอ | ร่าง → ส่งแล้ว → อนุมัติ / ปฏิเสธ / ยกเลิก (ห้ามข้ามสถานะ) | `draft`, `submitted`, `approved`, `rejected`, `cancelled` |
| ประวัติสถานะ | ใครเปลี่ยนสถานะเมื่อไร พร้อมเหตุผล (กลุ่ม 4) | ตาราง `request_history` |
| ประกาศ | แบนเนอร์บนหน้า Public ที่มีช่วงเวลาแสดง (กลุ่ม 5) | ตาราง `announcements` |
| Audit log | บันทึกกลางว่าใครทำอะไรกับข้อมูลใด (ส่วนกลาง) | `audit_log`, `logAudit` (⏳ ผู้สอนเตรียม) |
