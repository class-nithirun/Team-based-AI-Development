# Memory hub ของ ubu-biolink

โฟลเดอร์นี้คือ "ความจำร่วม" ของทุกกลุ่มและ AI ทุกตัว (Cline, Kilo Code, AI Review bot)
ทุกตัวอ่านไฟล์ในนี้ก่อนเริ่มงาน — กำหนดไว้ใน `AGENTS.md` หัวข้อ Memory protocol
(path เดียวกับ `practice-app/docs/memory/` ของวันที่ 1 — วันนี้มีไฟล์เพิ่ม 3 ไฟล์)

| ไฟล์ | เก็บอะไร | ใครแก้ได้ |
|---|---|---|
| `conventions.md` | รูปแบบโค้ด API Error และ Git ที่ทุกกลุ่มใช้ร่วมกัน | มนุษย์ ผ่าน PR + ผู้สอน Review |
| `decisions.md` | บันทึกการตัดสินใจ (เพิ่มต่อท้ายเท่านั้น ห้ามลบของเก่า) | มนุษย์ ผ่าน PR + ผู้สอน Review |
| `glossary.md` | คำศัพท์ของระบบ ↔ ชื่อในโค้ด | มนุษย์ ผ่าน PR |
| `lessons.md` | สิ่งที่ AI ทำผิดบ่อย และวิธีป้องกัน | มนุษย์ ผ่าน PR (มาจาก Review / Retro) |

ไฟล์ที่เกี่ยวข้องนอกโฟลเดอร์นี้:

- `docs/features.md` — โจทย์ 5 กลุ่ม × 4 โมดูล, ช่วงเลข migration, สัญญาระหว่างกลุ่ม
- `docs/api-spec.md` — สัญญา API (ทุกกลุ่มเพิ่มส่วนของตัวเอง)
- `docs/specs/<issue>-<ชื่อ>.md` — Spec ของแต่ละงาน (Designer เขียน, คนอนุมัติ)
- `docs/handoff/<issue>.md` — บันทึกส่งต่องาน Design → Build → Review → Human

## กติกา

1. AI **ไม่แก้ไฟล์ในโฟลเดอร์นี้เอง** — เสนอผ่านหัวข้อ "เสนอเพิ่มใน memory" ใน Handoff แล้วให้คนเปิด PR
2. ทุกการแก้ memory ต้องผ่าน PR และ Review เหมือนโค้ด (กัน memory ผิด หรือถูกแทรกคำสั่งถึง AI)
3. เขียนสั้น ชัด มีวันที่และเลข Issue/PR อ้างอิงเสมอ
4. ห้ามใส่ข้อมูลส่วนบุคคล รหัสผ่าน หรือ API Key
5. ถ้าเรื่องใดเกี่ยวกับกลุ่มเดียว เขียนชื่อกลุ่มกำกับ (เช่น `[กลุ่ม 4]`) ให้กลุ่มอื่นข้ามได้
