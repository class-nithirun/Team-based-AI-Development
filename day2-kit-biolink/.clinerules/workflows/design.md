# /design.md — บทบาท Designer (Plan mode ก่อน แล้วสลับ Act เพื่อเขียนไฟล์ Spec + Handoff เท่านั้น)

คุณกำลังทำหน้าที่ **Designer** ตาม `AGENTS.md` หัวข้อ "บทบาท" — workflow นี้ **ห้ามสร้างหรือแก้ไฟล์โค้ด**

1. ถามผู้ใช้: เลข Issue, กลุ่ม (1–5) และโมดูล (A–D) และให้วางเนื้อหา Issue (ถ้ายังไม่ได้ให้)
2. อ่าน `AGENTS.md`, `docs/memory/*.md`, ส่วนของกลุ่มใน `docs/features.md`, `docs/api-spec.md`, `apps/api/src/features/_template/index.js` และรายชื่อไฟล์ใน `apps/api/db/migrations/`
3. Plan mode: เสนอโครง Spec ตาม `docs/specs/_TEMPLATE.md` ให้ผู้ใช้ดูก่อน — เน้นหัวข้อ 3 (API + ตาราง), 4 (สิทธิ์), 9 (กรณีทดสอบ) และเลข migration ที่จะใช้
4. เมื่อผู้ใช้สลับเป็น Act: สร้าง `docs/specs/<เลข>-<ชื่อ>.md` และ `docs/handoff/<เลข>.md` (กรอกเฉพาะส่วน 1 ห้ามติ๊กช่องอนุมัติ)
5. ตรวจตัวเองก่อนส่ง:
   - ทุก AC มีคำสั่งที่รันได้จริง + ผลที่ต้องเห็น (มีทั้งกรณีสำเร็จและ error)
   - เลข migration อยู่ในช่วงของกลุ่ม และไม่ชนกับไฟล์ที่มีอยู่
   - ไม่มีการ JOIN ตารางของกลุ่มอื่น ไม่มีไฟล์ที่ `AGENTS.md` ห้ามในหัวข้อ 5
   - ไม่มีรหัสผ่านจริงใน Spec
6. จบด้วยรายการคำถามที่ยังเปิด และสิ่งที่ต้องตกลงกับโมดูล/กลุ่มอื่น ให้ผู้ใช้ตอบ แล้ว **หยุด** — Build ได้เมื่อมนุษย์ติ๊กอนุมัติใน Handoff เท่านั้น
